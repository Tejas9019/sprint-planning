## UX Requirements

The editor should immediately communicate:

* Where the workflow starts
* How data moves
* Which branch is active
* Which node failed
* What data is being passed
* What AI decisions are being made
* Whether the workflow is live

Focus on creating the most detailed and realistic workflow editor possible.

Avoid marketing content, dashboards, analytics pages, landing pages, onboarding screens, or generic admin layouts.

The entire screen should feel like a professional workflow automation IDE used by enterprise AI teams.
